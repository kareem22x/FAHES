# فاحص — تطبيق الجوال

تطبيق **React Native / Expo** لمنصّة «فاحص»، مستقلّ عن تطبيق الويب في نفس المستودع.

## التشغيل

```bash
npm install
cp .env.example .env      # ثم عدّل القيم عند الحاجة
npm start
```

| الأمر | الوظيفة |
|---|---|
| `npm start` | خادم التطوير (Expo) |
| `npm run android` / `npm run ios` | فتح المحاكي مباشرةً |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run lint` | ESLint بإعداد `eslint-config-expo` |

## البيئة

`.env.example` يوثّق المتغيّرين المطلوبين. القاعدة الحاكمة: **بادئة `EXPO_PUBLIC_`
وحدها هي التي تُشحن إلى الجهاز** — فلا يوضع سرّ في هذا الملف أبدًا.

⚠️ للجوال أثناء التطوير المحلي استخدم **عنوان LAN** (`http://192.168.x.x:4001`)
لا `localhost`: الجهاز أو المحاكي لا يرى `localhost` الخاص بحاسوبك.

## المعمارية — لماذا `/api/*` لا Supabase مباشرةً

ترحيل `20261001000010_rls_deny_by_default.sql` يسحب كل صلاحيات `anon` و`authenticated`
من جداول الطلبات والعروض ⇒ **قراءة القاعدة من الجهاز مرفوضة بالتصميم**، لا لأن مفتاحًا
ناقصًا. لذلك يتكلّم التطبيق مع مسارات `/api/*` القائمة في تطبيق الويب بترويسة
`Authorization: Bearer <Clerk session token>`، فيُعاد استخدام **كل** منطق الخادم
(فحص الملكية · التحقق من المدخلات · تسوية الدفع · قبول العروض) بلا نسخة ثانية تنحرف عنه.

> التفاصيل الكاملة — عقد العزل عن أداة بناء الويب · فخاخ ESLint · فخاخ الخطّ العربي —
> في `.workbuddy-ai/memory/MOBILE.md`.
